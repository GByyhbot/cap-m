# MANIA

当前版本：**2.0.2**。请先更新服务器，再更新模块。

## 导入模块

在 REX 中导入你的 **服务器地址/REX**，例如：

```text
http://192.168.1.100:8080/REX
```

也可以通过 **[GitHub 一键导入](https://rexnow.tv/widget?url=https%3A%2F%2Fraw.githubusercontent.com%2Fzxxlxj%2Frex-m%2Fmain%2Fdocs%2Fplugin-platform%2Fexamples%2Fmania%2Fmania.rex.js%3Fv%3D2.0.2)**，或复制集合地址：

```text
https://raw.githubusercontent.com/zxxlxj/rex-m/main/mania.rex?v=2.0.2
```

## 开始使用

1. 填写 **服务器地址**和 **API**。
2. 打开“获取播放账号”，点击选择主账号或备用账号。
3. 在“媒体缓存”中浏览电影、剧集，也可从播放器媒体详情页选择资源。

## 播放与缓存

- 点击播放时按需解锁，可能消耗额度。
- 播放后的直链会在下一次加载资源时同步到本机，缓存命中后直接播放。
- 直链按两小时与实际到期时间中较早者失效。
- 支持设置缓存容量，切换账号后使用各自的缓存。
- 显示文件大小和视频参数，2160P 统一显示为 4K。
